## Установка

Скачиваем аддон и закидываем в папку `папка игры/BepInEx/plugins`

## Управление
| Действие | Клавиша / Кнопка | Описание |
| -- | -- | -- |
| Включение / Выключение | F5 | Переключает режим свободной камеры и блокирует/разблокирует персонажей. |
| Поворот камеры | Зажатый ПКМ + Мышь | Скрывает курсор Windows и плавно вращает камеру по горизонтали и вертикали. |
| Горизонтальный полёт | W A S D | Движение относительно направления взгляда камеры. |
| Взлёт вверх | Space или E | Поднимает камеру строго по глобальной оси $Y$. |
| Спуск вниз | Left Ctrl или Q | Опускает камеру к полу. |
| Ускорение (Sprint) | Left Shift | Увеличивает скорость перемещения в 2.5 раза. |
